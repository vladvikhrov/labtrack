# LabTrack — учёт оборудования компьютерного класса с QR-кодами

**Кейс 5. Система инвентаризации оборудования.**
В компьютерном классе (ауд. 52-37) 30 ПК, 2 принтера и проектор. Лаборант узнаёт о поломках, только когда к нему подряд подходят несколько студентов. LabTrack решает это так: на каждом устройстве наклейка с QR-кодом → студент сканирует, входит и отмечает состояние → лаборант видит дашборд со статистикой и историю каждого устройства.

Веб-приложение на **Flask + SQLite** с авторизацией для двух ролей: **студент** и **лаборант**.

**Рабочий сайт:** https://wikhrov.pythonanywhere.com/

## Возможности

| Требование кейса | Реализация |
|---|---|
| На каждом ПК наклейка с QR-кодом | Раздел «QR-наклейки»: лист для печати, QR-коды генерируются на сервере (SVG) |
| Студент сканирует → видит страницу устройства | `/d/pc-15`; при первом сканировании — вход, после него сразу страница устройства. Вход запоминается на 30 дней |
| «Всё работает» / «Есть проблема» (мышь / клавиатура / монитор / ПО) | Страница устройства; у принтеров и проектора свои категории |
| Лаборант видит дашборд: «ПК-15 — 3 жалобы на мышь» | Карта класса, «Требуют внимания», жалобы по типу, журнал; обновление каждые 30 секунд |
| История: кто и когда сообщил | Карточка устройства: ФИО, группа, время, закрытие жалоб |
| Авторизация | Вход по логину и паролю, регистрация студентов по коду, управление пользователями у лаборанта |

## Роли и доступ

| Раздел | Адрес | Студент | Лаборант |
|---|---|:-:|:-:|
| Страница устройства (по QR-коду) | `/d/<код>` | ✓ | ✓ |
| Мои сообщения | `/me` | ✓ | ✓ |
| Дашборд, карточка устройства | `/lab/`, `/lab/device/<код>` | — | ✓ |
| Устройства, QR-наклейки | `/lab/devices`, `/lab/stickers` | — | ✓ |
| Пользователи: создать, заблокировать, сбросить пароль | `/lab/users` | — | ✓ |

## Быстрый старт на своём компьютере

```bash
python3 -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export REGISTRATION_CODE=CODE123                         # Windows: set REGISTRATION_CODE=CODE123
flask --app labtrack seed --demo                        # 33 устройства + демо-пользователи и сообщения
flask --app labtrack run --debug
```

Откройте http://127.0.0.1:5000. Демо-логины: лаборант `lab` / `lab12345`, студенты `ivanov`, `petrova`, `kim` / `student123`.

Тесты: `python -m unittest discover -s tests -v`.

## Команды администрирования

| Команда | Что делает |
|---|---|
| `flask --app labtrack seed [--pcs 30] [--demo]` | Создаёт аудиторию и устройства; `--demo` — тестовые пользователи и сообщения |
| `flask --app labtrack create-user LOGIN --name "ФИО" [--role lab\|student] [--group ИС-21]` | Создаёт пользователя, спрашивает пароль |
| `flask --app labtrack reset-password LOGIN` | Выдаёт временный пароль |
| `flask --app labtrack import-students students.csv` | Массово создаёт студентов из CSV и печатает их пароли |

## Настройки (переменные окружения)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `SECRET_KEY` | — (обязательна на сервере) | Ключ подписи сессий |
| `DATABASE_PATH` | `instance/labtrack.sqlite3` | Файл базы данных |
| `REGISTRATION_CODE` | пусто | Код самостоятельной регистрации студентов; пусто — регистрация выключена |
| `PUBLIC_BASE_URL` | адрес запроса | Адрес сайта для QR-кодов |
| `ROOM_NUMBER` | `52-37` | Номер аудитории |
| `TIMEZONE` | `Europe/Moscow` | Часовой пояс для отображения времени |
| `SESSION_DAYS` | `30` | Сколько дней помнить вход |
| `SESSION_COOKIE_SECURE` | `0` | `1` при работе по HTTPS |
